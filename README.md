# alarm-clock-app
A modern and responsive Alarm Clock Web Application with alarm management, snooze, dismiss, custom alarm tones, and local storage support.
# ⏰ AlarmX - Smart Alarm Clock

A modern and responsive Alarm Clock Web Application developed for Task 3.

## Features

- Live current time and date
- Digital clock
- AM/PM display
- 12-hour and 24-hour format
- Add multiple alarms
- Edit alarms
- Delete alarms
- Enable/disable alarms
- Alarm labels
- Multiple alarm tones
- Daily alarms
- Weekday alarms
- Weekend alarms
- Snooze functionality
- Dismiss functionality
- Alarm countdown
- Dark mode
- Browser notifications
- LocalStorage persistence
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Web Notifications API

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Make sure `alarm.mp3` is inside the `assets` folder.
4. Open `index.html` in a web browser.

## Important

Browser autoplay restrictions may prevent an alarm sound from playing until the user has interacted with the page.

A normal web application cannot guarantee an alarm will run if the browser/device is completely closed.
